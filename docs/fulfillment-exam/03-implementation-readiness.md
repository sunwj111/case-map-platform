## 3. 授权后实施顺序

1. **配置**：按考生账号改 `application.yml`（MySQL schema、Redis 前缀、MQ 若不用可保留不连）。  
2. **库表**：按 `02` 编写 `schema.sql` + 必要种子数据（客户、套餐、项目、人员技能）。  
3. **后端领域**：状态机 → 占用服务 → 派单事务 → 履约/异常/结算 → 权限拦截 → Redis 可用性缓存。  
4. **接口**：按 `02` 业务动作清单暴露 REST，禁止通用改状态。  
5. **前端**：列表/统计、预约表单、详情动作流；处理加载/空/失败/无权限/冲突。  
6. **测试**：JUnit（占用或状态机）+ 至少 2 个核心动作场景；补测试报告。  
7. **Readme**：假设、表关系、接口阶段、≥3 风险、占用历史保留说明。
