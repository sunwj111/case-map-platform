# 用例地图公司平台 · 开发任务清单 V2

> 基线：`prototype/用例地图_公司平台_P0增强原型.html`（2026-09-07 最新版本）  
> 目标：把当前前端内存态原型转成可部署、可持久化、可审计的 Java 平台。  
> 旧清单 `feature_map_tasks.md` 保留用于历史追溯；后续排期以本文件为准。

## 1. 与旧版的关键变化

- 范围从“报价域单功能点地图”升级为“公司级多领域平台”。
- 默认主链路改为：资产生产 → 评审校准 → 正式资产 → 全景/地图消费。
- 新增标准模式与仅用例模式、主数据四表、平台/领域/应用三级全景。
- 功能点详情按经典视图、布局地图、图谱三种模式统一建设。
- 图谱从旧版 P2 提升为 P0；变更影响、回归包导出纳入主链路。
- 新增版本基线、生命周期、同步中心、健康看板、租户与角色权限。

## 3. 状态定义

- `已完成`：存在正式 Java/契约实现，并有自动化测试。
- `部分完成`：Story 的独立子功能已正式实现，但整条验收尚未全部满足。
- `待开发`：原型可能可演示，但尚无正式服务或组件。
- `原型状态=已验证`：最新版原型已有完整交互，可作为验收参照。
- `原型状态=部分`：只有静态数据、toast 或降级示意。
