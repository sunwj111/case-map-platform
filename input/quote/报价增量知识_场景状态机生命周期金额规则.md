### 2. DesignCost（造价单）审核状态机

#### 2.1 状态（DesignCheckStatusEnum）

| code | 名称 | 说明 |
|---|---|---|
| 0 | INIT | 待提交 |
| 10 | SUBMITED | 待审核 |
| 20 | PASS | 审核通过 |
| 30 | REJECT | 审核拒绝 |
| 40 | CANCEL | 已取消 |
| 50 | INVALID | 已失效 |

#### 2.2 状态流转

- INIT(0) —提交→ SUBMITED(10) —审核通过→ PASS(20) —失效→ INVALID(50)
- SUBMITED(10) —审核拒绝→ REJECT(30) —重新提交→ SUBMITED(10)
- SUBMITED(10) / INIT(0) —取消→ CANCEL(40)

关键规则：

- `canEdit()`：仅 INIT(0) 或 REJECT(30) 可编辑。
- 审核通过：`validTime=now`；`invalidTime=now+15天`（标准）或 `now+30天`（长租，由 `judgeNeedLockStockAndExpire` 判定）。
- 提交：`checkStatus=SUBMITED(10)`，校验互斥，可能自动提交。

#### 2.3 审核时效（DesignCostAuditConstant）

- 初次审核 20 min；试点订单 30 min；复审 15 min
- 审核时段 9:00–22:00；即将超时提前 10 min；同消息不重复提醒 5 min

### 3. 实勘（Survey/Review）状态机

#### 3.1 状态（ReviewStatusEnum）

| code | 名称 | 说明 |
|---|---|---|
| 0 | DSH | 待审核 |
| 10 | SHTG | 审核通过 |
| 20 | TZTG | 调整通过 |
| 30 | SHBH | 审核驳回 |
| 40 | YZF | 已作废 |

#### 3.2 状态流转

- DSH(0) —通过→ SHTG(10) —作废→ YZF(40)
- DSH(0) —调整通过→ TZTG(20) —作废→ YZF(40)
- DSH(0) —驳回→ SHBH(30) —作废→ YZF(40)

关键规则：

- 终态 `whetherFinishStatus()`：SHTG / TZTG / SHBH（YZF 不算已处理终态）。
- `cancelSKReview()`：按房源取消待审核记录。
- `judgeGroupWhetherSurvey()`：BIM 参数、户型、整屋可实勘综合判定。
- 非可实勘房间价格：表价格 > BOM 价格时生成虚拟物品补差。

### 4. 申诉（Appeal）状态机

#### 4.1 申诉状态（AppealStatus）

| code | 名称 | 说明 |
|---|---|---|
| 10 | WAIT_FIRST_CHECK | 待初审 |
| 20 | WAIT_LAST_CHECK | 待终审 |
| 30 | FIRST_CHECK_REJECT | 初审已拒绝 |
| 40 | LAST_CHECK_PASS | 终审已通过 |
| 50 | LAST_CHECK_ADJUST | 终审有调整 |
| 60 | LAST_CHECK_REJECT | 终审已拒绝 |
| 70 | CHECK_COMPLETE | 已完成 |

审核类型：FIRST_CHECK(5) / LAST_CHECK(10)。  
审核结果：PASS(10) / ADJUST_PASS(20) / REJECT(30)。

#### 4.2 状态流转与 finallyCost

- 初审 PASS / ADJUST_PASS → WAIT_LAST_CHECK(20)
- 初审 REJECT → FIRST_CHECK_REJECT(30)
- 终审 PASS → LAST_CHECK_PASS(40)，finallyCost=estimatedCost
- 终审 ADJUST_PASS → LAST_CHECK_ADJUST(50)，finallyCost=checkAdjustCost
- 终审 REJECT → LAST_CHECK_REJECT(60)，finallyCost=standardCost

特殊：新建申诉可跳过初审直接 WAIT_LAST_CHECK；`auto_appeal_switch` 可自动审核。

相关实体：`QuotationsAppeal`、`QuotationsAppealCheck`。

## 二、生命周期（失效 / 预占 / 作废）

### 1. 失效类型（DesignCostExpireTypeEnum）

| code | 名称 | 说明 |
|---|---|---|
| 1 | STANDARD_DAYS_15 | 标准价 15 天后失效 |
| 2 | AUDIT_DAYS_30 | 造价审核通过 30 天后失效 |
| 3 | CONTRACT_INVALID | 收房合同作废 |
| 4 | COPY_INVALID | 造价单改价作废 |
| 999 | HISTORY_INVALID | 历史刷数作废 |

`noCheckInvalidTime()`：CONTRACT_INVALID、COPY_INVALID。

### 2. 禁止失效类型（DesignProhibitExpireTypeEnum）

- HAS_HIRE_CONTRACT(1)：有签约合同，阻止失效
- CONTRACT_INVALID(2)：签约合同作废

### 3. 库存预占（DesignLockStockEnum）

- SUCCESS(1) / FAIRE(2) / FAIRE_TO_SUCCESS(3)

### 4. 失效触发链

- 时间：Foxy `DesignCostTimeExpireListener` → `expireDesignCost`
- 合同：`YZContractConsumerListener`（签约阻止失效 / 作废触发 CONTRACT_INVALID）
- 改价：`CopyDesignCostListener` → COPY_INVALID
- `handleDesignCostExpire`：置 INVALID(50)、更新明细、通知、`cancelLockStock` 释放库存

### 5. 预占

- `judgeNeedLockStockAndExpire`：心舍市场化产品或非新建（续约）可不占库存
- 审核通过长租场景：invalidTime=+30 天并 `DesignLockStockEvent`；标准 +15 天

## 三、金额规则判定表

### 1. OfferRule 核心

- offerType：通用 / 画3D / 不画3D / 套内
- quantityType：销售标准数量 / BIM / 数量公式
- totalPriceRule：QUANTITY_PRICE / FIXED_PRICE
- offerRule / quantityRule：FEL 表达式
- auditScene：全部 / 仅设计师 / 仅造价审核

### 2. 物品总价

- FIXED_PRICE：总价=单价
- QUANTITY_PRICE：总价=单价×数量
- 租赁（ZL + rentalCycle）：总价=数量×单价×周期
- 去利润：totalPrice/(1+profitRate)
- 汇总：Σ itemTotalPrice、Σ noProfitPrice
- 精度：四舍五入 2 位；`maxPriceLeveling` 找平

### 3. 灵之智能折扣

- ruleType=INTELLIGENT_DISCOUNT；城市/全国、优先级、生效期
- 条件：开间、卧室数、金额阈值
- 折后价=原价×discountRate；仅定制设计模式 + 灵之智能套组

### 4. 溢价与标准出房价

- PZSJ / LZ / BZYJXS → 定价系统 `computeStandardPrice`
- 先 k2，后定价系统

### 5. 审核金额校验

- whetherAuditStandard / whetherCheckAmount / auditScene
- 报价提交适用 ALL+仅设计师；造价审核适用 ALL+仅造价审核
